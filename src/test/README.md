# 预约模块测试运行说明

## 运行前准备

1. 启动 MySQL。
2. 篮球馆价格为 200 元/小时，营业时间包含 09:00—11:00。
3. 羽毛球馆价格为 100 元/小时，营业时间包含 14:00—16:00。
4. 运行第四至第六条用例前，数据库中应存在普通用户 `user01`；若不存在，先运行第一条用例。
5. 运行第三至第六条用例前，启动系统并确认 `http://localhost:8888/` 可以访问。
6. 本机已安装 Google Chrome。

## 第一条用例：RES-H-001

运行命令：

```text
mvn -Dtest=Reservation001Test test
```

检查内容：

- 篮球馆预约时间为 09:00—11:00；
- 预约时长为 2 小时；
- 总价为 400 元；
- 订单状态为未审核。

## 第二条用例：RES-H-002

运行命令：

```text
mvn -Dtest=Reservation002Test test
```

检查内容：

- 羽毛球馆预约时间为 14:00—16:00；
- 预约时长为 2 小时；
- 总价为 200 元；
- 订单状态为未审核。

## 第三条用例：RES-H-003

运行命令：

```text
mvn -Dtest=Reservation003Test test
```

检查内容：

- 自动打开 Chrome，以未登录状态进入篮球馆详情页；
- 点击预约时提示登录；
- 页面跳转到登录页；
- 不生成订单。

## 第四条用例：RES-H-004

运行命令：

```text
mvn -Dtest=Reservation004Test test
```

检查内容：

- 登录 `user01` 并进入预约页面；
- 选择 09:00—10:00 后清空场馆名称；
- 提交时显示必填提示；
- 页面仍停留在预约页面；
- 不生成订单。

## 第五条用例：RES-H-005

运行命令：

```text
mvn -Dtest=Reservation005Test test
```

检查内容：

- 登录 `user01` 并进入预约页面；
- 输入不存在的场馆“游泳馆”；
- 选择 09:00—10:00；
- 显示“场馆不存在”且不能提交；
- 不生成订单。

## 第六条用例：RES-H-006

运行命令：

```text
mvn -Dtest=Reservation006Test test
```

检查内容：

- 登录 `user01` 并进入预约页面；
- 输入前后带空格的“ 篮球馆 ”；
- 选择 09:00—10:00；
- 系统给出明确提示且不出现异常页面；
- 不生成错误订单。
