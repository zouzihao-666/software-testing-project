# 预约模块测试运行说明

## 运行前准备

1. 启动 MySQL。
2. 篮球馆价格为 200 元/小时，营业时间包含 09:00—11:00。
3. 羽毛球馆价格为 100 元/小时，营业时间包含 14:00—16:00。
4. 运行第四至第十七条用例前，数据库中应存在普通用户 `user01`；若不存在，先运行第一条用例。
5. 运行第三至第十七条用例前，启动系统并确认 `http://localhost:8888/` 可以访问。
6. 本机已安装 Google Chrome。

## 第一条用例：RES-H-001

运行命令：

```text
mvn -Dtest=Reservation001Test test
```

检查内容：

- 篮球馆预约时间为 09:00—11:00；
- 预约时长为 2 小时；
- 总价为 400 元；
- 订单状态为未审核。
